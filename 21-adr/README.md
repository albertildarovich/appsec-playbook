# Architecture Decision Records (ADR)

> **Этот раздел расширен и реорганизован → [`../Engineering/adr/`](../Engineering/adr/)**

ADR — документирование архитектурных решений. Почему выбрали X, а не Y.
Какие риски остаются.

## Новая структура

В новой версии ADR стали библиотекой архитектурных решений:

```
ADR-001: Почему выбрали OAuth вместо Session
ADR-002: Почему выбрали Semgrep для SAST
ADR-003: Почему WAF работает в Fail Open
ADR-004: Почему используется Vault
ADR-005: Почему выбрали RBAC
...

Формат каждой записи:
1. Контекст — что происходило
2. Проблема — какую задачу решали
3. Варианты — какие были альтернативы
4. Решение — что выбрали и почему
5. Trade-offs — чем пришлось пожертвовать
6. Последствия — к чему привело решение
```
