# 🎙️ Interview Notes

> Готовые ответы и концепты для подготовки к собеседованиям на позицию AppSec Engineer / DevSecOps.

## Структура

| Раздел | Описание |
|--------|----------|
| [AppSec](appsec.md) | Общие вопросы по Application Security |
| [DevSecOps](devsecops.md) | CI/CD, SAST, DAST, SCA, pipelines |
| [Threat Modeling](threat-modeling.md) | STRIDE, DFD, Attack Trees |
| [BSIMM](bsimm.md) | BSIMM vs SAMM vs SSDF |
| [SAST](sast.md) | Taint Analysis, Semgrep, ложные срабатывания |
| [DAST](dast.md) | ZAP, Burp, типы сканирования |
| [Web Security](web-security.md) | XSS, SQLi, CSRF, SSRF |
| [Behavioral](behavioral.md) | STAR, конфликты, работа с командами |
| [System Design](system-design.md) | Security в архитектуре |
| [HR](hr.md) | Вопросы про зарплату, ожидания |

## Формат ответа

Каждый ответ строится по схеме:

```
🎯 Вопрос: [формулировка вопроса]
💡 Концепция: [1-2 предложения сути]
📝 Ответ: [развёрнутый ответ]
🔗 Связи: [связанные темы]
```

## Как использовать

1. Открыть нужный раздел
2. Найти вопрос
3. Прочитать ответ
4. Проговорить вслух (рекомендуется)
