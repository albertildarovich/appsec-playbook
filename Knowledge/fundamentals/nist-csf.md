# NIST Cybersecurity Framework (CSF)

## Определение

NIST CSF — это фреймворк кибербезопасности, разработанный NIST для улучшения кибербезопасности критической инфраструктуры и организаций.

- **Voluntary**: добровольный (но часто обязателен для government contractors)
- **Risk-based**: основан на оценке рисков
- **Common language**: общий язык для бизнеса и безопасности

## Структура CSF 2.0

CSF состоит из **6 функций** (ранее было 5, в CSF 2.0 добавили Govern):

### 1. Govern (Управление)
- Cybersecurity strategy
- Risk management
- Roles and responsibilities
- Policies and procedures

### 2. Identify (Идентификация)
- Asset management
- Business environment
- Risk assessment
- Supply chain risk

### 3. Protect (Защита)
- Access control
- Awareness training
- Data security
- Maintenance
- Protective technology

### 4. Detect (Обнаружение)
- Anomalies and events
- Continuous monitoring
- Detection processes

### 5. Respond (Реагирование)
- Response planning
- Communications
- Analysis
- Mitigation

### 6. Recover (Восстановление)
- Recovery planning
- Improvements
- Communications

## CSF vs SSDF

| Критерий | CSF | SSDF |
|----------|-----|------|
| Scope | Вся организация | Software только |
| Focus | Cybersecurity program | Secure development |
| Audience | CISO, Board | Engineering, AppSec |
| Categories | 6 functions, 23 categories | 4 groups, 19 practices |

## CSF в контексте AppSec

AppSec инженеру CSF нужен для:
1. Понимания, как AppSec вписывается в общую программу безопасности
2. Коммуникации с CISO и менеджментом на одном языке
3. Определения security controls для compliance

## Ключевые тезисы

- CSF — фреймворк для всей организации, не только для разработки
- Risk-based подход
- Общий язык для бизнеса и безопасности
- CSF 2.0 добавил Govern как отдельную функцию
- SSDF дополняет CSF для secure development
