# Checklists

Готовые чек-листы для ежедневной работы AppSec инженера.

## Как использовать

1. Открываешь нужный чек-лист
2. Проходишь по пунктам
3. Отмечаешь результат
4. Фиксируешь findings

## Содержание

| Чек-лист | Когда использовать |
|----------|-------------------|
| [Security Review](security-review.md) | Перед каждым major release |
| [API Review](api-review.md) | При review любого API |
| [Threat Modeling](threat-modeling.md) | При проектировании нового функционала |
| [Docker Review](docker.md) | При ревью Dockerfile / docker-compose |
| [Kubernetes Review](kubernetes.md) | При ревью K8s манифестов |
| [Release](release.md) | Перед выходом в production |
