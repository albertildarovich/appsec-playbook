| customer | Обычный пользователь. Может просматривать товары, добавлять в корзину, оставлять отзывы | Регистрация |
| deluxe | Премиум-пользователь. Дополнительный функционал (возможно) | Оформление Deluxe Membership |
| admin | Администратор. Полный доступ к управлению | ?? (предположительно через уязвимости) |

| Method | Path | Параметры | Описание |

## Заметки и наблюдения

### [CRIT] Критические находки

1. **Открытая директория /ftp**
   - Доступна через robots.txt: `Disallow: /ftp`
   - Содержит файлы — возможно, конфиденциальные данные
   - **Риск:** Disclosure чувствительных данных

2. **XSS в поиске**
   - HTML-теги (`<h1>`) отражаются в ответе
   - Возможна Stored/Reflected XSS атака

3. **SQLi в поиске (предположительно)**
   - Кавычка (`'`) меняет количество результатов (1 элемент вместо обычного)
   - Требуется дальнейшее тестирование

4. **JWT токен содержит хеш пароля**
   - Payload JWT: `password: "5f4dcc3b5aa765d61d8327deb882cf99"` (MD5 от "password")
   - Это грубое нарушение безопасности: пароль НЕ должен быть в токене
   - Хеш MD5 — устаревший алгоритм, легко брутится

5. **JWT содержит внутренние данные**
   - `lastLoginIp: "0.0.0.0"` — IP-адрес пользователя
   - `profileImage: "/assets/public/images/uploads/default.svg"` — путь к аватарке
   - `role: "customer"` — роль можно попробовать подменить

### [MED] Средние находки

6. **Форма оплаты Deluxe Membership**
   - Запрашивает номер карты — есть риск небезопасной обработки платежей

7. **Swagger через нестандартный путь**
   - `/api-docs/` работает, но `/swagger/` редиректит на socket.io — странное поведение

8. **Чат-бот неактивен**
   - Требует LLM API (возможно, нужно настроить ключ)

### [LOW] Информационные находки

9. **179 challenge'ей на Score Board**
   - Хорошая метрика покрытия тестов безопасности

10. **Профиль пользователя**
    - Можно менять email, имя и загружать аватар — поверхность для атак
