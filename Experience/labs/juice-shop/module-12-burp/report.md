# Модуль 12: Burp Suite

> **Цель:** Освоить базовые и продвинутые функции Burp Suite
> **Формат:** работа с инструментом

---

## План

- [ ] Proxy — перехват и модификация запросов
- [ ] Repeater — повторная отправка запросов
- [ ] Intruder — автоматизированный перебор
- [ ] Decoder — кодирование/декодирование
- [ ] Comparer — сравнение ответов
- [ ] Logger — анализ всех запросов

---

## Пройдено

| Функция | Статус | Результат |
|---------|--------|-----------|
| Proxy/Intercept | ✅ | Перехватили запрос, модифицировали body, добавили `role:admin` |
| Repeater | ✅ | Использовался для повторной отправки запросов |
| Intruder | ✅ | Подобрали пароль `admin123` для admin@juice-sh.op (bruteforce) |
| Decoder | ✅ | Декодировали JWT payload (password MD5, role, bid, нет exp) |
| Comparer | ✅ | Сравнили ответы `/api/Users` и `/rest/products/search?q=` для разных ролей — ответы **идентичны** (подтверждение отсутствия RBAC) |
| Logger | ✅ | Просмотрена история всех запросов через Proxy: методы, URL, статусы, время |

## Вывод

- **Intruder** подтвердил отсутствие rate limiting — 6 попыток подбора без блокировки
- **Decoder** показал уязвимости JWT (MD5, alg:none, без Exp)
- **Comparer** визуально подтвердил: customer и admin получают одинаковые данные — RBAC не работает на сервере
- **Logger** показал полную историю HTTP-трафика через Proxy
